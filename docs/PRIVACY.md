# Privacy

AgentInspect runs **entirely on your machine**. Repository scans, file reads, and optional local AI (Ollama / LM Studio) do not send your source code or scan results to AgentInspect servers — there are no AgentInspect-operated backend services.

The app may persist settings (e.g. chosen model, scoring profile) under your OS app data directory. Optional **GitHub Releases** downloads are served by GitHub, Inc.

Contact for privacy questions: maintainer via GitHub issues on this repository.
