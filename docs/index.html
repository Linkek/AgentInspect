The problem no one graphs

Every chat loads hidden instructions: always-on rules, nested AGENTS.md files, copied skills, and megabyte MCP manifests. Costs add up before you write a single prompt.

Without AgentInspect

  • Guessing which files load every turn
  • Same policy pasted in five toolchains
  • 2,000-line rules nobody dares delete
  • Editing generated .claude mirrors by mistake

With AgentInspect

  • Health score + ranked issues per platform
  • Exact & near-duplicate detection
  • Local AI drafts a leaner diff — you approve
  • RoleSync canonical paths front and center

Deep file intelligence
